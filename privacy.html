3. Какие данные собираются

При заполнении формы «Записаться на замер» Сайт собирает:

  • имя;
  • номер телефона;
  • комментарий (что нужно изготовить, пожелания к заказу).

Указывать эти данные пользователь может только добровольно и только для того, чтобы с ним связались по вопросу заказа.

4. Цели обработки

Данные собираются исключительно для того, чтобы связаться с пользователем, уточнить детали и организовать выезд мастера на замер. Данные не используются для рекламных рассылок и не передаются третьим лицам в иных целях.

5. Как обрабатывается заявка

Заявка проходит следующий путь: форма на Сайте → сервис автоматизации n8n → уведомление в Telegram → таблица Google Sheets, где заявки фиксируются для последующей обработки. Отдельной CRM-системы Оператор не использует.

Технически данные могут передаваться следующим сервисам в объёме, необходимом для доставки и учёта заявки:

  • сервис автоматизации n8n (n8n Cloud);
  • мессенджер Telegram;
  • Google LLC (сервис Google Sheets).

Эти сервисы выступают технической инфраструктурой для доставки заявки Оператору и самостоятельно не используют данные в собственных целях.

6. Срок и принципы хранения

Данные хранятся не дольше, чем это необходимо для обработки заявки и работы с клиентом, либо до отзыва согласия пользователем. Оператор принимает разумные организационные меры для защиты данных от неправомерного доступа.

Сайт использует счётчик Яндекс.Метрики для оценки посещаемости и поведения посетителей (в том числе Вебвизор и карту кликов). При этом автоматически могут собираться технические данные: IP-адрес, тип устройства и браузера, страницы переходов, файлы cookie. Эти данные обезличены и не позволяют напрямую установить личность посетителя без дополнительной информации.
